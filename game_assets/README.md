# Thư Mục Tổng Hợp Asset (Chỉ Các Asset Thực Tế Dùng Trong Game)

Thư mục này gom toàn bộ các file asset hình ảnh mà dự án game thực sự sử dụng:
1. **Asset lấy từ Stardew Valley** (332 files):
   - Đặt trong `stardew_valley/`
   - Chỉ gồm đúng 4 loài vật nuôi trong game (Gà trắng, Bò trắng, Lợn, Cừu), không có dê/vịt/khủng long...
   - Chỉ gồm 10 nhân vật dân làng thực tế xuất hiện trong game (`SDV_CHARACTERS` + Leah).
   - Đầy đủ cây trồng, chuyển động nông dân, hầm mỏ, địa hình, rào chắn, công trình đang chạy.
2. **Asset lấy từ ngoài / tự tạo bên ngoài** (26 files):
   - Đặt trong `outside_sources/`
   - Gồm 16 nông sản Việt Nam khi chín, chuồng thủ công, máng ăn/nước, sạp hàng, menu chính, icon app.
3. **Danh mục chi tiết**:
   - Tra cứu chi tiết tại: [DANH_SACH_ASSETS.md](./DANH_SACH_ASSETS.md)
